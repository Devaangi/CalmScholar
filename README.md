CalmScholar – Student Planner

Study smarter. Feel calmer.

CalmScholar is a student-friendly web project designed to help students organize their academic tasks, plan their study sessions, check in with their moods, and write study notes in one place.

Built using HTML, CSS, and JavaScript, this project demonstrates the fundamentals of front-end web development through a simple, interactive, and easy-to-use interface.

✨ Features

🏠 Dashboard – A welcoming home page with an overview of the project.

📝 My Tasks – Add tasks to your to-do list and mark them as completed by clicking on them.

📅 Study Planner – Add subjects and specify how many minutes you want to study.

😊 Mood Check – Select your current mood and receive a supportive message.

📒 Study Notes – Write and display study notes directly on the page.

🎨 Simple UI – A soft pastel color palette and a clean layout.

📱 Responsive Design – Basic responsive styling for smaller screens.

🚀 Getting Started

You can run CalmScholar locally on your computer by following these steps.

Clone this repository:

git clone <your-repository-url>

Open the downloaded project folder.

Make sure all HTML files, index.css, and index.js are in the same folder.

Open index.html in your web browser.

Navigate between the pages using the navigation menu.

No additional libraries or installations are required.

⚠️ Current Limitations

Tasks and study plans are currently managed in the page and are not permanently stored.

Study notes are displayed on the page but are not saved persistently.

The mood check provides predefined supportive messages and does not store mood history.
